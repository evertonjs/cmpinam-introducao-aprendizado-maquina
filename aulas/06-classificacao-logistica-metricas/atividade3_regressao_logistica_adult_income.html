Atividade 3 - Regressão Logística

📌 Objetivo

Aplicar o modelo de Regressão Logística em um problema real de classificação binária, analisando o dataset, observando o nível de balanceamento do atributo alvo, realizando o pré-processamento necessário e avaliando o desempenho do modelo com métricas adequadas.

📊 Dataset

Nesta atividade, utilizaremos o dataset Adult Income (Census), cujo objetivo é prever se uma pessoa possui renda anual:

  • >50K
  • <=50K

Esse é um problema de classificação binária, portanto é adequado para o uso da Regressão Logística.

Carregue os dados com o código abaixo:

import pandas as pd

url = "https://archive.ics.uci.edu/ml/machine-learning-databases/adult/adult.data"

columns = ["age", "workclass", "fnlwgt", "education", "education_num",
           "marital_status", "occupation", "relationship", "race", "sex",
           "capital_gain", "capital_loss", "hours_per_week", "native_country", "income"]

df = pd.read_csv(url, names=columns, na_values=" ?", skipinitialspace=True)

🧹 Parte 3 - Pré-processamento

Para usar a Regressão Logística, será necessário preparar os dados.

  1. Remova os registros com valores ausentes.
  2. Separe os atributos preditores em X e o atributo alvo em y.
  3. Transforme as variáveis categóricas em variáveis numéricas usando One-Hot Encoding.

Use como base:

df = df.dropna()

X = df.drop("income", axis=1)
y = df["income"]

X = pd.get_dummies(X, drop_first=True)

🤖 Parte 5 - Treinamento do Modelo

Treine um modelo de Regressão Logística com os dados preparados.

from sklearn.linear_model import LogisticRegression

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

Após o treinamento, gere as previsões para o conjunto de teste.

y_pred = model.predict(X_test)

📊 Parte 7 - Curva ROC e AUC

Agora, avalie o modelo com a Curva ROC e a métrica AUC.

from sklearn.metrics import roc_curve, roc_auc_score
import matplotlib.pyplot as plt

y_prob = model.predict_proba(X_test)[:, 1]

fpr, tpr, _ = roc_curve(y_test, y_prob, pos_label=">50K")

plt.figure(figsize=(7,5))
plt.plot(fpr, tpr, label="Curva ROC")
plt.plot([0,1], [0,1], linestyle="--")
plt.xlabel("Taxa de Falsos Positivos (FPR)")
plt.ylabel("Taxa de Verdadeiros Positivos (TPR)")
plt.title("Curva ROC")
plt.legend()
plt.show()

print("AUC:", roc_auc_score((y_test == ">50K").astype(int), y_prob))
