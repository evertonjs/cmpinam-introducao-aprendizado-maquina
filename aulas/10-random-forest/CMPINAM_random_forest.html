Relembrando: árvore de decisão

Uma árvore de decisão aprende uma sequência de perguntas para separar os dados.

Ela é intuitiva, fácil de visualizar e costuma ser um bom primeiro modelo para problemas de classificação.

Mas existe um problema

Uma única árvore pode se ajustar demais aos dados de treino e errar mais em exemplos novos.

A árvore escolhe divisões para separar os dados até chegar a uma decisão.

3

O problema de depender de uma única árvore

Alta variância

Pequenas mudanças nos dados podem gerar árvores diferentes.

Overfitting

A árvore pode memorizar padrões muito específicos do treino.

Decisão frágil

Uma divisão ruim no início pode afetar todo o restante da árvore.

Ideia: em vez de confiar em uma árvore, podemos consultar várias.
4

A intuição da Random Forest

Random Forest é um conjunto de várias árvores de decisão. Cada árvore aprende a partir de uma versão ligeiramente diferente dos dados.

Ideia central

Uma árvore individual pode errar, mas a combinação de várias árvores tende a produzir uma decisão mais estável.

Passo 1: criar dados por bootstrap

O bootstrap cria uma nova base de treino sorteando linhas da base original com reposição.

Como há reposição, uma mesma linha pode aparecer mais de uma vez, enquanto outras podem ficar de fora.

Por que isso é útil?

Cada árvore treina com uma “visão” diferente do conjunto de dados.

Exemplo: a linha C apareceu duas vezes; a linha D ficou de fora.

Passo 3: selecionar atributos aleatoriamente

Além de usar amostras diferentes, a Random Forest também limita os atributos candidatos em cada divisão da árvore.

Em uma árvore comum

Em cada nó, o algoritmo pode avaliar todos os atributos disponíveis para escolher a melhor divisão.

Na Random Forest

Em cada nó, o algoritmo avalia apenas um subconjunto aleatório de atributos.

Renda
Escolaridade

8

Por que inserir aleatoriedade?

Diversidade

As árvores ficam menos parecidas entre si.

Menos dependência

O modelo não depende apenas de uma divisão dominante.

Melhor generalização

O conjunto tende a ser mais robusto para dados novos.

Random Forest combina muitas decisões imperfeitas para produzir uma decisão mais confiável.

Como a floresta faz uma previsão?

Para classificação, cada árvore vota em uma classe. A classe mais votada é a previsão final.

Exemplo intuitivo

Se 3 árvores votam na classe A e 1 árvore vota na classe B, a Random Forest retorna classe A.

E se o problema for de regressão?

Em regressão, as árvores não votam em classes. Cada árvore prevê um valor numérico, e a floresta geralmente usa a média das previsões.

previsão final = média das previsões das árvores

Nesta aula, o foco principal está na classificação, mas a ideia geral também vale para regressão.

Out-of-bag: as amostras que ficaram de fora

Ao criar uma amostra bootstrap, algumas linhas da base original não são sorteadas.

Essas linhas são chamadas de out-of-bag para aquela árvore.

Uso importante

Elas podem ser usadas para testar árvores que não foram treinadas com elas.

Exemplo

LinhaStatus na árvore 1
Ausada no treino
Busada no treino
Cusada no treino
Dout-of-bag
Eusada no treino

Out-of-bag error

O erro out-of-bag é uma forma de estimar o desempenho da Random Forest usando as amostras que ficaram fora do treino de cada árvore.

Para cada amostraidentifique as árvores nas quais essa amostra ficou fora do bootstrap.
Faça a previsãouse apenas essas árvores para prever a classe da amostra.
Compare com o valor realverifique se a previsão foi correta ou incorreta.
Calcule o erro geralagregue os erros de todas as amostras avaliadas.

Comparação: árvore única × Random Forest

Aspecto Árvore de decisão Random Forest
Interpretação Mais simples de visualizar. Mais difícil, pois combina muitas árvores.
Estabilidade Pode mudar bastante com pequenas alterações nos dados. Tende a ser mais estável.
Overfitting Mais propensa se crescer sem controle. Geralmente reduz o risco pela combinação de árvores.
Desempenho Bom como modelo simples e explicável. Frequentemente apresenta melhor desempenho preditivo.
15

Principais hiperparâmetros

n_estimators

Número de árvores na floresta. Mais árvores podem melhorar a estabilidade, mas aumentam o custo computacional.

max_depth

Profundidade máxima de cada árvore. Controla o quanto cada árvore pode se especializar.

max_features

Número de atributos considerados em cada divisão.

min_samples_leaf

Número mínimo de amostras em uma folha. Ajuda a evitar folhas muito específicas.

16

Vantagens e limitações

Vantagens

  • Bom desempenho em muitos problemas tabulares.
  • Menos sensível a pequenas variações nos dados.
  • Funciona bem sem muita preparação complexa.
  • Permite estimar importância dos atributos.

Limitações

  • Menos interpretável que uma árvore única.
  • Pode ser mais pesado para treinar e prever.
  • Importância de atributos pode exigir cuidado na interpretação.
  • Não substitui uma boa análise dos dados.
